# Custom-Die
Roll custom dice!

- Create as big and varying dice as you want and roll as many as you want at a time (assuming you don't select the no duplicate rolls option before rolling, in which case rolling stops once all possible sides have been rolled).
- You can save and load die side configurations; they are saved as comma-separated plain text lists.
- Creating a die in the app does not allow for duplicate sides but if you truly must have duplicate sides, load a text file with the duplicate sides included and you can roll that die.
- Currently only one kind of die can be rolled at a time.
